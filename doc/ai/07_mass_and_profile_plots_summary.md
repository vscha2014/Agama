# 07 — Резюме сессии: профиль-корнер и суммарная гистограмма масс

Краткое summary работы в чате (диагностические/визуализационные скрипты пост-обработки

## 1. `py/profile_likelihood_corner.py` — доработки

Corner-график профиль-правдоподобия (`Δpenalty`) по осям
`incl, Q, gh, rh, rho0*Upsilon, Upsilon, log10(J)`.

- **Верхний треугольник → корреляции Пирсона.** Раньше ячейки `j>i` были пустыми
  (`axis('off')`). Теперь в них выводится коэффициент корреляции Пирсона между парой
  параметров по отобранным точкам (`Δpenalty ≤ --view-dpen`). Размер шрифта
  масштабируется по `|r|`.
  - Функция-помощник `pearson(a, b)` (защита от вырожденных случаев → «—»).
  - **Важно:** это ОПИСАТЕЛЬНАЯ корреляция ВЫБОРКИ ОПТИМИЗАТОРА (BoTorch),
    а НЕ постериорная корреляция параметров (см. вопрос PI #16).
- **Палитра заливки — «спокойная» мята→розовый.** Диверджентная
  `LinearSegmentedColormap` `mint_pink`: мята при `r<0`, белый при `r≈0`, розовый при
  `r>0`. Текст тёмный (`#2b2b2b`) для читаемости на пастели.
- **Ось наклонения — равномерный (категориальный) масштаб.** `incl` — дискретная сетка
  с неравномерным шагом (сгущение к 90°: 70, 80, 85, 86, 87, 87.5, 88.5, 89, 89.5, 90).
  Введена функция `axis_spec(...)`, разделяющая:
  - **биннинг** `penalty` — по РЕАЛЬНЫМ значениям (для `digitize`/профилей);
  - **отрисовку** — по РАВНОМЕРНЫМ категориальным координатам (0,1,2,…) для дискретных
    осей, с тиками, подписанными реальными градусами.
  Так область около 90° больше не сжимается. Для непрерывных осей — прежнее линейное
  поведение.

Первая строка таблицы (там, где по оси `Δpen`): диагональ `(0,0)` — 1D-профиль
`Δpen(incl)`, а ячейки правее — корреляции `incl` с остальными параметрами.

Дефолтный вывод: `py/profile_corner_theta0.5.pdf` (в `.gitignore`).

## 2. `py/mass_histogram_all_incl.py` — новый самостоятельный скрипт

Гистограмма масс модели **по всем наклонениям СУММАРНО**, БЕЗ расчёта J-фактора,
со **взвешиванием по penalty**.

- Отдельный блок mass-histogram из `py/J_factor_Sersic_Fornax_P21_symm.py`, но:
  одна суммарная гистограмма (не по каждому наклонению отдельно) и penalty-веса.
- **Про penalty:** в исходном `make_mass_histograms` гистограмма масс НЕ была взвешена
  (каждая модель = 1); по penalty там взвешивалась ТОЛЬКО статистика J. Здесь добавлено
  взвешивание `w = exp(-(penalty − pen_min)/pen_sigma)` (как для J-статистики),
  с нормировкой суммы весов на число моделей. Опция `--no-weight` отключает.
- Массы (`M_tot`, `M_DM`) считаются аналитически через `agama.Density`
  (гало spheroid + звёзды Sersic). Это НЕ production-оптимизация и НЕ генерация орбит.
- Константы модели из §7: `q_ap = 1−0.31`, `D = 143 kpc`, `massSt = 14.0`,
  `Sersic_m = 0.80`, `scaleRst = π·D/180·16.4/60 kpc`, `alphah = 2, betah = 3`.
- Стек как в оригинале: ТМ (тёмный) снизу, звёзды (светлый) сверху; в бине точки
  группируются по близкой доле ТМ (±0.10), высота субколонки = сумма весов.
- Глобальный penalty-cutoff по всем наклонениям (адаптивный, 30% лучших, ≈1.39).
- Источник данных: сырые `4Ups*`-файлы ИЛИ `--combined-file` (учитывает кратность
  `count`, чтобы совпадать с чтением сырых строк). Combined-файл удобен без доступа к
  Яндекс.Диску.
- **Вывод в консоль:** для `r < 1 кпк` и полной массы печатаются взвешенные медианы
  (с 1σ) полной массы, а также ОТДЕЛЬНО массы ТМ и звёзд
  (`M_ТМ = M·f_dm`, `M_звёзды = M·(1−f_dm)`).

Пример (combined-файл, взвешенно):

```
       r < 1.0 кпк: M50=15.64  [15.50, 15.71] (1σ) [1e7 Msun]
         в т.ч. ТМ: M50=15.08  [14.91, 15.15] (1σ) [1e7 Msun]
     в т.ч. звёзды: M50=0.57  [0.55, 0.61] (1σ) [1e7 Msun]
      полная масса: M50=772.54 [687.20, 806.78] (1σ) [1e7 Msun]
         в т.ч. ТМ: M50=771.66 [686.45, 805.94] (1σ) [1e7 Msun]
     в т.ч. звёзды: M50=0.87  [0.84, 0.94] (1σ) [1e7 Msun]
```

### Запуск

Модуль AGAMA лежит в `/data/gala/Agama`, поэтому нужен `PYTHONPATH`:

```bash
# через combined-файл (без доступа к Яндекс.Диску)
PYTHONPATH=/data/gala/Agama .venv-ai/bin/python py/mass_histogram_all_incl.py \
  --combined-file py/Jcomputed_from_raw_theta0.5.txt --out-dir py

# напрямую из сырых 4Ups (нужен доступ к Яндекс.Диску, запуск как gala)
python py/mass_histogram_all_incl.py
```

Опции: `--no-weight`, `--radii 0.5,1.0`, `--cutoff`, `--target-fraction`, `--nbins`.
Выходные PDF (`py/mass_histogram_all_incl_*.pdf`) добавлены в `.gitignore`.
