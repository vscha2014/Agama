## 1. Проверка единиц: исправление конверсии J-фактора

### Система единиц расчётного кода

- `agama.setUnits()` не вызывается → внутренние единицы с `G = 1`.
- Длина — кпк; скорости делятся на `vscale = sqrt(2·6.67/3.086) ≈ 2.079` км/с.
- Из `G = 1`: единица массы = `vscale² · 1 кпк / G_phys ≈ 1.005·10⁶ M☉`, т.е.
  **масса в коде — в 10⁶ M☉** (`massSt = 14.0` → 1.4·10⁷ M☉).
- `Density.density()` возвращает плотность в `10⁶ M☉/кпк³`;
  `enclosedMass()` / `totalMass()` — в `10⁶ M☉` (`interface_python.cpp`,
  `conv->massUnit = 1`).

### Найденная ошибка

Строка `rho_conv = 1.989e33 / 1.602e-10 / kpc_to_cm**3` смешивала СГС (M☉ в граммах)
и СИ (1 ГэВ в джоулях) и не учитывала множитель 10⁶. J-фактор был занижен на ~40
порядков.

### Исправление

```python
rho_conv = 1e6 * 1.989e33 / 1.783e-24 / (kpc_to_cm**3)   # 10^6 Msun/kpc^3 -> GeV/cm^3
```

(1 ГэВ/c² = 1.783·10⁻²⁴ г.) Итоговая конверсия `J = J_code · rho_conv² · kpc_to_cm`.

## 2. Учёт `Upsilon` и деprojекции звёзд

Согласовано с главным скриптом `Fornax_P21_symm_PCA_w3Sersic_yaVM.py`:

- `compute_J_factor(..., Upsilon)`: `densitynorm = rho0 * Upsilon`.
- `compute_model_masses(..., Upsilon)`: гало `densitynorm = rho0 * Upsilon`,
  звёзды Sersic `mass = massSt * Upsilon`.
- `Upsilon` берётся из столбца 5 лог-файлов (`data_good[:, 5]`).
- Добавлены `q_ap = 1 − 0.31` и `compute_axRZst(incl)`:
  `axRZst = sqrt(q_ap² − cos²i) / sin i` (вместо жёсткого `axRZst = 1.0`).
- Константы звёзд: `massSt = 14.0`, `Sersic_m = 0.80`,
  `scaleRst = π·D/180·16.4/60` кпк, `D = 143` кпк.

## 3. Гистограммы масс (`compute_model_masses`, `make_mass_histograms`)

Два PDF: `mass_histogram_1.0_Sersic_incl{incl}.pdf` (M(<1 кпк)) и
`mass_histogram_total_Sersic_incl{incl}.pdf` (`Density.totalMass()` для гало+звёзды).
Гистограмма на 0.3 кпк по решению PI не строится.

- **Ось X** — полная масса (ТМ + звёзды) в `10⁷ M☉` (`m_vals = M_code / 10`).
- **Ось Y** — число моделей в столбце.
- Каждый столбец — стек: тёмная часть (`#2c3e50`) = доля ТМ, светлая (`#bdc3c7`) =
  звёзды (`N·f_dm` и `N·(1−f_dm)`).
- Внутри бина полной массы модели группируются по доле ТМ: если доли отличаются
  более чем на 0.10 — отдельные субколонки, иначе — одна.
- **Полная масса:** линейная шкала, фиксированный диапазон 550–850 (`10⁷ M☉`),
  заголовок «полная масса», без легенды и литературных линий.
- **r < 1 кпк:** линейная шкала, авто-диапазон `[min − 10 %, max + 10 %]`,
  легенда «Тёмная материя / Звёзды», литературных отметок нет (были добавлены, затем
  убраны по просьбе PI).
- Имя файла без суффикса `_theta`: `make_output_filename(..., theta_max_deg=None)`
  опускает его (масса — сферическая/полная, а не в угле θ, как J).
- Вызов — в конце скрипта, после corner-plot, на тех же `_data_c, _J_c`
  (θ = 0.5°, `do_corner_plot`).

Гистограмма масс **не** взвешена по penalty (каждая модель = 1); взвешенный вариант
по всем наклонениям — в `py/mass_histogram_all_incl.py` (см. `07_mass_and_profile_plots_summary.md`).
